# 0020. 有效的括号 (Valid Parentheses)

> 难度：Easy ｜ 日期：2026-08-04（提前完成） ｜ 解法：栈（数组模拟）

## 思路

用数组模拟栈存左括号。遇到右括号时和栈顶配对：

- 先判栈空（`top == 0`）→ 空栈遇到右括号直接 `false`
- 栈顶是 `stack[top-1]`（`top` 是元素个数，不是下标）
- 配对 → 出栈；不配对 → `return false`
- 遍历完栈必须为空

辅助函数 `pairs()` 统一处理左右括号映射。

## 复杂度

时间 O(n)，空间 O(n)

## 踩坑（08-04 记录）

1. **pairs 调用方向反了**：写了 `pairs(stack[top])`（传左括号）→ 应 `pairs(s[i])`（传当前遍历到的字符）
2. **栈顶索引**：栈顶在 `stack[top-1]` 不是 `stack[top]`
3. 不匹配要 `return false`，不是继续压栈
4. 中文全角冒号 `：` 打代码反复 3 次 → 写代码前切英文输入法
